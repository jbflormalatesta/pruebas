# Fotos de las cuatro estaciones (colección)

Cada foto aparece sola en la ficha de su especie si se llama así (en minúsculas, salvo la letra del
código):

- `A-71-primavera.jpg`
- `A-71-verano.jpg`
- `A-71-otono.jpg` ← «otono», sin tilde
- `A-71-invierno.jpg`

Formato .jpg, con el lado mayor de unos 1200 píxeles y menos de 300 KB. Se ven cuadradas en la ficha
(se recortan al centro) y completas al tocarlas. Sin chicas ni chicos reconocibles.

Para subirlas: **Add file** → **Upload files** → arrastrarlas → **Commit changes**. Se pueden subir
hasta 100 archivos por vez.

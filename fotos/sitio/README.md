# Fotos del sitio

Subí acá las fotos con **exactamente** estos nombres (en minúsculas, formato .jpg). Cada una aparece
sola en su lugar; mientras falte, la página muestra una lámina verde con la silueta de un árbol.

| Archivo | Dónde aparece | Qué conviene que muestre |
|---|---|---|
| `portada.jpg` | Portada, arriba | Una vista amplia del Jardín: senderos, árboles, luz de día |
| `visita.jpg` | «Visitá el Jardín» | El ingreso o un sendero, que invite a recorrer |
| `el-jardin.jpg` | «El Jardín» | Los árboles añosos de la quinta, el vivero o el equipo trabajando |

**Proporción:** apaisada **3:2** (por ejemplo 1600 × 1067 píxeles). Si la foto tiene otra proporción,
se recorta sola al centro.
**Peso:** menos de 400 KB por foto. Las del celular pesan mucho: achicalas antes, por ejemplo en
<https://squoosh.app> (ancho 1600, calidad 75).
**Personas:** sin chicas ni chicos reconocibles.

Para subirlas: entrá a esta carpeta → **Add file** → **Upload files** → arrastrá las fotos → **Commit changes**.
